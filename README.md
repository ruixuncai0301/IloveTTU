# 🧺 大同大學舊德惠宿舍 - 洗衣房排隊系統 (IloveTTU)

> 告別抱著衣服下樓卻發現沒洗衣機的窘境！首創專為大同大學舊德惠宿舍打造的智慧預約系統。

**原創開發與設計：** Rax

## 💡 創作動機 (Why I Built This)
身為住在舊德惠宿舍的學生，我常常遇到抱著衣服下樓卻沒洗衣機可用的情況，或是衣服洗好了卻沒人拿，導致機器被佔用。為了解決這個生活痛點，我決定發揮資工系的專長，從零到有設計了這套大同大學專屬的洗衣房排隊系統。

這不僅僅是一份作業，更是我將課堂理論實際落地的第一個完整專案，希望能用技術為宿舍生活帶來實質的改變。

## ✨ 核心概念與功能
* 📱 **線上預約排隊**：在房間就能先卡位，不用在洗衣房苦等。
* ⏳ **即時狀態查看**：隨時掌握目前有幾台空機、幾台運作中。
